# CLIFC

Command-line tools for working with [IFC](https://technical.buildingsmart.org/standards/ifc/) models.

## Install

```bash
pip install -e .
```

## Quick Example

Merge two IFC files into one output file:

```bash
clifc merge -o merged.ifc model-1.ifc model-2.ifc
```
